# Kar Seng's dotfiles
---
My own personal dotfiles

# Installation
---
Run the following commands:

```bash
git clone https://github.com/karseng/dotfiles.git
cd dotfiles
./install.sh
```
## Mac OS setup
- (Optional) - xcode-select --install
- Install [Homebrew](https://brew.sh/)
- Run `./brew.sh`
- Run `./install.sh`

# Update
For updating all the pacakges (brew, mise, zsh)
Run the following commands:
```bash
./updates.sh
```
